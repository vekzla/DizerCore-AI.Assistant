## Opcodes / packet flow (verify names in Opcodes.cpp for 12.1.0 — naming varies)  
CMSG_* = client→server, SMSG_* = server→client  
Cast:   CMSG_CAST_SPELL → HandleCastSpellOpcode → Spell::cast → SMSG_SPELL_START/GO  
Move:   CMSG_MOVE_* → MovementHandler.cpp → MovementInfo::Read  
Quest:  CMSG_QUEST_GIVER_* (accept/complete/query) → QuestHandler.cpp  
Gossip: CMSG_GOSSIP_HELLO / CMSG_GOSSIP_SELECT_OPTION → gossip_menu chain  
Item:   CMSG_USE_ITEM → SpellHandler / Item use  
Combat: CMSG_ATTACK_SWING → Unit::AttackerStateUpdate  
Updates: SMSG_UPDATE_OBJECT (spawn/despawn), SMSG_QUEST_UPDATE_*,  
         SMSG_GOSSIP_MESSAGE, SMSG_MOVE_* (movement broadcast)  
"Invalid opcode" = struct layout mismatch vs client build — check the  
packet class in Server/Packets/*Packets.cpp first, then the handler.  
  
## Common wiring patterns  
- Quest credit: smart_scripts action_type=58, action_param1=quest id;  
  NPC must have source_type=0 row with entryorguid=creature_template.entry  
- New quest needs: quest_template + quest_objectives (+ quest_poi markers,  
  creature_queststarter/questender rows or gossip hook, conditions gates)  
- New NPC needs: creature_template + creature spawn row + (smart_scripts,  
  gossip, creature_text, loot) + conditions to gate behavior  
- Spell scripting: C++ script named in spell_script_names, loaded via  
  AddSC_* registration — a spell with no row and no script does nothing  
- Loot chain: creature_loot_template.Reference → reference_loot_template  
  (recursive; check parent chain before adding rows)  
- Hot reload: .reload smart_scripts / quest_template / creature_template /  
  conditions — C++ changes still need recompile + restart

## Common Errors → First Places to Check  
"Invalid opcode"          → *Packets.cpp struct vs 12.1.0 client layout  
"Spell X not found"       → sSpellStore entry; DBC load order at startup  
"Quest credit not firing" → smart_scripts action 58 param1 vs quest id;  
                            conditions SourceType 31/20 gating it  
"Creature not spawning"   → creature row, phaseMask/PhaseID, spawnMask  
"NPC won't gossip/quest"  → gossip_menu chain, creature_template.npcflag,  
                            conditions SourceType 13/14/20  
"Quest not available"     → quest_template_addon prereqs, conditions 20,  
                            character_queststatus prior quest state  
"Loot never drops"        → ChanceOrQuestChance>0, reference chain complete,  
                            conditions SourceType 1  
"No such row in conditions" → missing SourceType/SourceGroup entry
