## Common Patterns
- Quest credit fires via SMART_ACTION_ADD_QUEST_CREDIT (58), action_param1 = quest ID
- Spell casting from script: SMART_ACTION_CAST (11), action_param1 = spell ID
- Phase transitions: SMART_EVENT_HEALTH_PCT, event_param1 = percent (0-100)
- Timed actions: SMART_EVENT_TIMER, event_param1 = initial ms, event_param2 = repeat ms
- Hot reload without restart: .reload smart_scripts, .reload quest_template, .reload creature_template

## Common Errors and Causes
"Invalid opcode" — packet structure mismatch with 12.1.0 client
"Spell X not found" — Spell.dbc missing entry or DBC not loaded at startup
"Quest credit not firing" — check smart_scripts action_param1 vs quest_template entry
"Creature not spawning" — check creature table + phase_mask in spawn
"No such row in conditions" — conditions table missing SourceType/SourceGroup for the case
